# Separate contracts checkout

This repo is the canonical Launch contract checkout. In the Mercurifi workspace it is `contracts/launch`; Trade is a separate private repo at `contracts/trade`. Read current audit and release runbooks; a local Foundry pass or dry-run is evidence, not authorization to broadcast. Review storage layout, source hashes and gas snapshot changes. Keep mainnet and testnet records separate, and do not repeat completed Safe/recovery tests without a new reason.
