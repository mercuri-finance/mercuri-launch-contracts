# Separate Mercurifi contracts repository — Codex

This public Git repository owns the Launch source, tests, release tooling, storage layouts and canonical deployed records. In the Mercurifi workspace it lives at `contracts/launch`; Trade is the separate private repository at `contracts/trade`. Read `../../docs/handoff/mainnet-handover.md`, `../../docs/runbooks/mainnet-application.md` and the current audit reports when the workspace is present. Run `bash script/check-contracts.sh` for a candidate change. Do not broadcast, upgrade, alter Safe/governance or rewrite deployment records without specific release authorization. Never read `.env` or disclose signer material. The local `.agents/skills/mercuri-contract-release/` provides the review path.
